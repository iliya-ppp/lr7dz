# Домашнее задание к работе 2

## Условие задачи

Напишите программу, которая интерпретирует степени 2 в соответствующие международные приставки (10 – K, 20 – M, G, T, P, E). Использование условного оператора `if-else` не рекомендуется.

## 1. Алгоритм и блок-схема

### Алгоритм

1. **Начало**
2. Инициализировать целочисленную переменную для хранения степени:
    - `degree = 0` (защита от некорректного ввода).
3. Запросить у пользователя ввод целого числа.
4. Передать значение переменной `degree` в управляющую структуру множественного выбора `switch`.
5. Сравнить значение с ключевыми кейсами:
    - Если `10` -> Вывести латинскую букву "K" (Кило)
    - Если `20` -> Вывести латинскую букву "M" (Мега)
    - Если `30` -> Вывести латинскую букву "G" (Гига)
    - Если `40` -> Вывести латинскую букву "T" (Тера)
    - Если `50` -> Вывести латинскую букву "P" (Пета)
    - Если `60` -> Вывести латинскую букву "E" (Экса)
6. Если совпадений не найдено, перейти к ветке `default`:
    - Вывести диагностическое сообщение "Неизвестная степень".
7. Завершить работу структуры `switch` с помощью операторов `break`.
8. **Конец**

## 2. Реализация программы

```c
#define _CRT_SECURE_NO_DEPRECATE
#include<locale.h>
#include <stdio.h>

int main() 
{
    setlocale(LC_ALL,"RUS");
    int degree = 0; 
    printf("Введите степень: ");
    scanf("%d", &degree);

    switch (degree) 
    {
        case 10:
            printf("K\n"); // Строго латинская K
            break;
        case 20:
            printf("M\n"); // Строго латинская M
            break;
        case 30:
            printf("G\n");
            break;
        case 40:
            printf("T\n");
            break;
        case 50:
            printf("P\n");
            break;
        case 60:
            printf("E\n");
            break;
        default:
            printf("Неизвестная степень\n");
            break;
    }

    return 0;
}
```
